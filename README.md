# Business Sales, Profit and Customer Insights

## Project Overview
This project explores business sales and profit performance using Microsoft Excel. It presents key metrics and visualisations in an interactive dashboard to help users examine business performance.

## Objectives
- Analyse sales and profit trends over time.
- Compare sales performance across product categories and regions.
- Explore customer-level performance.
- Present key business metrics using an interactive dashboard.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Charts and KPI metrics
- Slicers and filters

## Dashboard Features
- Sales and profit KPI cards
- Year-wise profit analysis
- Month-wise sales trends
- Product category and customer analysis
- State-wise sales comparison
- Interactive filtering

## Project File
- `Business Analysis Dashboard.xlsx` — Excel workbook containing the dashboard and analysis.

## Key Learnings
- Organising and exploring business data.
- Building interactive Excel dashboards.
- Comparing business metrics and identifying patterns.
- Presenting data visually to support business analysis.

## Future Improvements
- Add verified findings and business recommendations.
- Extend the analysis using SQL and Power BI.

## Note
This project is intended for learning and portfolio development. Findings and recommendations should be supported by analysis of the underlying dataset.
